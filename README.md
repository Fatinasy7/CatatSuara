# CatatSuara

CatatSuara saat ini masih berupa kerangka Laravel. Halaman yang tersedia adalah halaman sambutan bawaan Laravel; fitur pencatatan suara dan autentikasi/login belum dibuat.

## Panduan

- [Menjalankan proyek secara lokal dengan Laragon](PANDUAN-LARAGON.md)
- [Penggunaan aplikasi dan informasi akun](PANDUAN-PENGGUNAAN.md)

## Teknologi

- PHP 8.3 atau lebih baru
- Laravel 13
- MySQL/MariaDB (untuk konfigurasi Laragon di panduan instalasi)
- Node.js dan npm untuk membangun aset frontend
